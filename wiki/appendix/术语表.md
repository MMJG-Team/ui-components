# 术语表

本表汇总 `@mmjg/ui-components` 文档中出现的核心术语，给出中文名、英文对照与简明释义，便于在阅读各页时快速对照。

| 术语 | 英文 | 释义 |
| --- | --- | --- |
| 瀑布流 | Masonry | 一种不规则高度的网格布局，元素按列排列并自动填充到最短列，常见于图片墙。本库核心组件 `Masonry` 即实现该布局。 |
| CSS Modules | CSS Modules | 一种 CSS 模块化方案，将每个样式文件中的类名编译为带哈希的全局唯一名，实现样式隔离。本库统一以 `style.module.less` 命名样式文件。 |
| CSS 自定义属性 | CSS Custom Properties / CSS Variables | 以 `--name` 声明、以 `var(--name)` 消费的 CSS 变量。本库用其作为 props 到样式/动画的桥梁，由 JS 在 `useEffect` 中写入。 |
| Barrel 文件 | Barrel file | 一个仅做 `export *` 聚合的入口文件，用于把多个模块的导出统一对外暴露。本库 `src/components/index.ts`、`src/hooks/index.ts` 等均为 barrel 文件。 |
| 命令式句柄 | Imperative Handle / useImperativeHandle | React `useImperativeHandle` 钩子，配合 `forwardRef` 向父组件暴露命令式方法（如 `scrollToTop`），作为声明式 props 之外的「逃生舱」。 |
| 视口 | Viewport | 浏览器或滚动容器中当前可见的区域。本库 `VerticalViewportMonitor` 模块与 `useScrollViewArea` hook 均围绕视口监测展开。 |
| 竞态 | Race Condition | 多个异步操作因完成顺序不确定而导致结果不可预测的情况。本库 `SyncTaskQueue`、`UniqueRequest` 模块用于规避请求竞态。 |
| 防抖 / 节流 | Debounce / Throttle | 限制高频回调执行频率的两种手段。防抖在停止触发后才执行（本库 Masonry 用 `debounce(10ms)` 合并 resize），节流按固定间隔执行。 |
| 虚拟滚动 / 可视区裁剪 | Virtual scrolling / view area culling | 只渲染落入可视区的元素、跳过屏外元素的优化技术。本库 `useScrollViewArea` 通过 `viewRange` 实现可视区裁剪。 |
| Monorepo | Monorepo | 将多个包/项目放在同一个 Git 仓库中管理的工程模式。本仓库以 pnpm workspace 管理 `packages/ui-components` 与 `site` 两个工作区。 |
| peerDependencies | peerDependencies | npm 包声明的「对等依赖」，要求宿主项目自行安装指定版本的依赖（如 `react`），避免重复打包与多实例。本库将 `react`、`react-dom`、`axios` 声明为 peer。 |
| ESM | ECMAScript Module | JavaScript 官方模块系统，使用 `import` / `export` 语法。本库 `"type": "module"` 且构建产物仅产出 ESM 格式。 |
| Changeset | Changeset | Changesets 工具中用于声明一次变更影响哪些包、提升何种版本（patch/minor/major）的 Markdown 文件，存放于 `.changeset/` 目录。 |
| forwardRef | forwardRef | React 高阶组件 API，允许组件将内部 DOM 或子组件的 ref 转发给父组件。本库 `Masonry` 用其暴露命令式句柄。 |
| rAF | requestAnimationFrame | 浏览器提供的、在下一次重绘前调用回调的 API，常用于驱动动画。相较于 `setTimeout`，rAF 与浏览器刷新率同步，更平滑。 |
| overscan | overscan | 虚拟滚动中在可视区上下额外预渲染的一段区域，用于避免快速滚动时出现空白。本库 `useScrollViewArea` 通过 `overscanHeight` 控制。 |
