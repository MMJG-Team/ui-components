# 05 · 目录结构详解

## 顶层结构

```
ui-components/                        # monorepo 根
├── .changeset/                       # Changesets 版本管理
├── .github/workflows/                # CI/CD 工作流
├── packages/
│   └── ui-components/                # 库本体（对外发布的 npm 包）
├── site/                             # Rspress 文档站
├── global.d.ts                       # 根全局类型声明
├── package.json                      # monorepo 根 package.json
├── pnpm-workspace.yaml               # pnpm 工作区声明
├── pnpm-lock.yaml
├── tsconfig.json                     # 根 TS 配置（服务文档站）
└── README.md
```

### Masonry 组件内部结构（最复杂）

```
components/Masonry/
├── hooks/
│   ├── useColumnCount.ts             # 列数计算（断点 + maxColumnCount）
│   ├── useMasonryLayout.ts           # 持有 MasonryLayout 实例 + React 投影
│   ├── useResizeObserver.ts          # 容器尺寸监听
│   └── useScrollViewArea.ts          # 可见区域 + 触底加载
├── models/
│   ├── ImageModel.ts                 # 图片加载/管理模型（class）
│   └── MasonryLayout.ts              # 瀑布流布局算法（class）
├── index.tsx                         # 组件视图（forwardRef）
├── types.ts                          # MasonryProps / MasonryRef 等
└── style.module.less
```

> Masonry 是库内唯一采用「models（class）+ hooks（桥接）+ index.tsx（视图）」三件套结构的组件，其他组件通常是 `index.tsx + style.module.less` 两件套，Menu3D 额外带一个 `hooks/` 子目录。

### 文档与源码的对应关系

| 文档路径 | 对应源码 |
| --- | --- |
| `zh/components/<Name>.mdx` | `packages/ui-components/src/components/<Name>/` |
| `zh/hooks/useXxx.mdx` | `packages/ui-components/src/hooks/useXxx.ts` |
| `zh/modules/<Name>.mdx` | `packages/ui-components/src/modules/<Name>.ts` |
| `_demo/components/<Name>/*.tsx` | 被 `.mdx` 中 ` ```tsx preview ` 引用的示例 |

## 命名约定速查

| 对象 | 约定 | 示例 |
| --- | --- | --- |
| 组件目录 | PascalCase | `BorderEffect/` |
| 组件文件 | `index.tsx` + `style.module.less` | — |
| Hook 文件 | camelCase，`use` 开头 | `useMouseDragOffset.ts` |
| Module 文件 | PascalCase，与类名一致 | `SyncTaskQueue.ts` |
| 样式类名 | kebab-case，`styles["xxx"]` 访问 | `styles["border-effect-core"]` |
| CSS 变量 | `--<component>-<prop>` | `--shimmer-width`、`--cube-size` |
| Props 类型 | `<Name>Props` | `ShimmerProps`、`MasonryProps<Item>` |
| Ref 类型 | `<Name>Ref` | `MasonryRef` |
