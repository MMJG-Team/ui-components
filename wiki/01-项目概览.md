# 01 · 项目概览

## 一句话定位

`@mmjg/ui-components` 是一个基于 **React 18 + TypeScript** 的前端组件库，沉淀自 [MMJG-Team](https://github.com/MMJG-Team) 的研发实践，提供**视图组件、React Hooks、功能模块与工具函数**四类能力。

## 仓库形态：pnpm Monorepo

项目根 [package.json](../package.json) 名为 `@mmjg/ui-components-monorepo`，通过 [pnpm-workspace.yaml](../pnpm-workspace.yaml) 声明两个工作区：

```yaml
packages:
    - "site"
    - "packages/*"
```

- `packages/ui-components` —— 库本体，对外发布的 npm 包。
- `site` —— 基于 Rspress 的文档站点，开发期通过 `workspace:*` 直接引用库的源码（见 [site/package.json](../site/package.json) 与 [rspress.config.ts](../site/rspress.config.ts) 中的别名 `@mmjg/ui-components → ../packages/ui-components/src/index.ts`）。

## 能力分类

库根入口 [src/index.ts](../packages/ui-components/src/index.ts) 仅 4 行，聚合四大类导出：

```ts
export * from "./modules";
export * from "./components"
export * from "./hooks" 
export * from "./utils"
```

| 分类 | 导出方式 | 代表成员 |
| --- | --- | --- |
| **components** | 具名 + 默认 | `Masonry`、`Menu3D`、`Shimmer`、`BorderEffect`、`PartitionLayout`、`Cube` |
| **hooks** | 具名 + 默认 | `useEvent`、`useMounted`、`useWindowSize`、`useBoxSizeObserver`、`useMouseDragOffset`、`useScrollPercent`、`useMockProgress`、`useAutoLoadMore` |
| **modules** | 具名 + 默认 | `SyncTaskQueue`、`UniqueRequest`、`VerticalViewportMonitor` |
| **utils** | 命名空间 | `AsyncUtil`（`delay`、`mockAsyncChunk`） |

> 注意 `utils` 采用 `export * as AsyncUtil` 命名空间导出，使用时为 `AsyncUtil.delay(ms)`，而非裸导出。

## 安装与使用

```bash
pnpm add @mmjg/ui-components
```

`peerDependencies` 要求宿主提供 `react >= 18`、`react-dom >= 18`、`axios >= 1.9.0`（`axios` 仅 `UniqueRequest` 依赖）。

```tsx
import { Masonry, useEvent, SyncTaskQueue, AsyncUtil } from "@mmjg/ui-components";
```

| `pnpm run publish:ui-components` | 发布库到 npm（CI 中调用） |

## 设计哲学

从源码可归纳出三条贯穿全局的设计取向：

1. **关注点分离**：纯逻辑下沉为「modules」（不依赖 React），可复用行为沉淀为「hooks」，可渲染单元封装为「components」。三者层层组合。
2. **运行时样式驱动**：大量使用 CSS 自定义属性（`--xxx`）作为组件 props → 样式的桥梁，避免内联样式重渲染，统一交给 Less + CSS Modules 管理（见 [CSS Modules 规范](./guides/CSS-Modules-与-Less-规范.md)）。
3. **声明式 API + 命令式逃生舱**：组件以 props 驱动为主，但对需要外部操控的场景（如滚动控制）通过 `forwardRef` + `useImperativeHandle` 暴露 ref API（典型：[Masonry](./components/Masonry.md)）。
