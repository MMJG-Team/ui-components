# 06 · 编码规范与代码风格

本章从源码归纳出本库事实遵循的编码规范与风格约定。库内**无 ESLint/Prettier 配置文件**，规范由代码本身与 TypeScript 严格选项共同约束（见 [工程化配置](./04-工程化配置.md)）。

## 1. 文件与导出

- **一文件一单元**：每个 hook / module / util 各占一个 `.ts` 文件，文件名与导出主名一致。
- **双导出**：所有公开单元同时提供**具名导出**与**默认导出**。
  ```ts
  export function useEvent<T>(...) { ... }
  export default useEvent;
  ```
- **Barrel 聚合**：每个目录用 `index.ts` 做 `export *`，最终汇于 [src/index.ts](../packages/ui-components/src/index.ts)。
- **utils 例外**：工具函数用命名空间导出 `export * as AsyncUtil`，调用形如 `AsyncUtil.delay(ms)`。
- **类型重导出**：因 `verbatimModuleSyntax`，类型重导出用 `export type *`：
  ```ts
  export * from "./models/ImageModel";
  export type * from "./types";
  ```

## 2. TypeScript 风格

- **严格模式全开**：`strict` + `noUnusedLocals` + `noUnusedParameters`。解构 props 不得留无用字段。
- **类型与接口**：props 多用 `type`，class options / 公共契约用 `interface`。
  ```ts
  export type ShimmerProps = { ... }              // props
  export interface VerticalViewportMonitorOptions { ... }  // 模块配置
  ```
- **泛型约束**：泛型组件用 `forwardRef` + 行内约束。
  ```ts
  forwardRef(function InternalMasonry<Item extends { id: ...; src: ... }>(
      props: MasonryProps<Item>, ref: React.Ref<MasonryRef>
  ) { ... })
  ```
- **枚举**：使用普通 `enum`（非 `const enum`，因 `isolatedModules`）。
- **类型导入**：仅作类型用时必须 `import type`：
  ```ts
  import { forwardRef, useImperativeHandle } from "react";
  import type { MasonryProps, MasonryRef } from "./types";
  ```

## 3. 组件编写规范

### 3.1 函数组件 + 默认参数

```tsx
export const Shimmer = (props: ShimmerProps) => {
    const { type = "text", width = 10, color = "#ffffffff", duration = 2 } = props;
    ...
};
export default Shimmer;
```

所有可空 props 必须给出默认值，解构在函数体顶部。

### 3.2 CSS 变量驱动样式（首选）

数值/颜色类 props 不写进内联 style，而是通过 `useEffect` 写入 CSS 自定义属性：

```tsx
const containerRef = useRef<HTMLDivElement>(null);
useEffect(() => {
    containerRef.current?.style.setProperty("--shimmer-width", `${width}px`);
}, [width]);
```

样式与动画由 `style.module.less` 中的 `var(--xxx)` 消费。**唯一例外**是布局类即时样式（如 `transform`、`height`），用内联 `style` 直接写。

### 3.3 类名拼接

统一用 `classnames` 库，禁止字符串拼接：

```tsx
<div className={classNames(styles.shimmer, styles[`shimmer-${type}`], className)}>
```

样式键用 kebab-case，访问用 `styles["xxx"]` 或 `styles[\`xxx-${var}\`]`。

### 3.4 命令式句柄

需要外部控制的组件用 `forwardRef` + `useImperativeHandle`，并导出对应的 `<Name>Ref` 类型：

```tsx
export type MasonryRef = {
    getScrollElement: () => HTMLElement | null;
    scrollToTop: (behavior?: ScrollBehavior) => void;
};
export const Masonry = forwardRef(function InternalMasonry(props, ref) {
    useImperativeHandle(ref, () => ({ getScrollElement: () => ..., ... }), [...]);
});
```

### 3.5 条件渲染

无 children 时不渲染：
```tsx
return children && (<div>...</div>);
```

## 4. Hook 编写规范

- **命名**：`use` 开头，camelCase。
- **容器参数**：统一 `HTMLElement | (() => HTMLElement)`，内部 resolve：
  ```ts
  const el = typeof container === 'function' ? container() : container;
  ```
- **稳定回调**：传给 `addEventListener` / `ResizeObserver` 的回调一律用 `useEvent` 包裹，避免闭包陈旧与重复订阅。
- **返回值**：多值返回用 `as const` 元组或对象。
  ```ts
  return [ref, boxSize] as const;          // 元组
  return { progress, start, complete, stop };  // 对象
  ```
- **清理**：所有副作用在 `useEffect` return 中清理（`disconnect`、`removeEventListener`、`clearTimeout`）。

## 5. 模块（modules）编写规范

- **纯 class，零 React 依赖**：`modules/` 下文件不得 `import` React。
- **构造函数接收配置**：配置用 `interface`，与默认值合并。
- **事件机制**：用 `mitt` 实例做事件广播（见 `SyncTaskQueue`）。
- **节流/防抖**：用 `lodash-es` 的 `throttle` / `debounce`。
- **显式清理方法**：提供 `dispose()` / `destroy()` / `clear()`，命名一致地释放监听与引用。

## 6. 样式规范（Less + CSS Modules）

- 文件名固定 `style.module.less`，`import styles from "./style.module.less"`。
- 顶层选择器即组件根，CSS 变量声明在根选择器上：
  ```less
  .border-effect {
      --border-width: 2px;
      --border-color: #ffffffff;
      .border-effect-content { margin: var(--border-width); }
  }
  ```
- 嵌套书写，`@keyframes` 内联在所属选择器内。
- 哈希规则由构建配置统一控制：`[name]__[local]___[hash:base64:5]`。

## 7. 注释规范

- **JSDoc 中文注释**：公共函数 / hook / class / 复杂逻辑用 `/** */` 中文说明参数与返回。
  ```ts
  /**
   * 滚动到指定元素
   * @param id 元素 id
   * @param options 滚动选项
   */
  ```
- **行内说明**：关键算法步骤用 `//` 中文行注（如 MasonryLayout 中的分列、裁剪逻辑）。
- **场景描述块**：复杂 hook 顶部用多行注释说明「场景描述」与「处理方案」（见 [useAutoLoadMore](../packages/ui-components/src/hooks/useAutoLoadMore.ts)）。

## 8. 依赖使用规范

| 场景 | 用什么 | 不用什么 |
| --- | --- | --- |
| 类名拼接 | `classnames` | 手动字符串拼接 |
| 防抖/节流 | `lodash-es` 的 `debounce`/`throttle` | 自实现 |
| 事件总线 | `mitt` | Node EventEmitter |
| 取消请求 | `AbortController` + axios signal | 自定义标志位 |
| 尺寸监听 | `ResizeObserver` | `resize` 事件（除非监听 window） |
| 动画帧 | `requestAnimationFrame` | `setInterval` 做动画 |

## 9. 命名总则

- 组件 / 类 / 类型：PascalCase。
- hook / 变量 / 函数：camelCase。
- 常量：UPPER_SNAKE_CASE（`DEFAULT_COLUMN_COUNT`、`ITEM_CLASS_NAME_PREFIX`）。
- CSS 类 / 变量：kebab-case。
- 私有成员：TS `private` 关键字，不靠命名下划线约定（库内 `UniqueRequest`、`VerticalViewportMonitor` 均如此）。
