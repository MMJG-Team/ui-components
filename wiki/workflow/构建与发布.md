# 构建与发布

## 简介

本页记录 `@mmjg/ui-components` 库的构建工具链、产物结构、发布流程与 npm 发布配置。库本体位于 [packages/ui-components/](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components)，由 Rolldown 打包，发布到 npm 公共仓库。

## 构建工具 Rolldown

库采用 [Rolldown](https://rolldown.rs/)（基于 Rust 的 Rollup 兼容打包器）进行构建，配置文件为 [packages/ui-components/rolldown.config.ts](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/rolldown.config.ts)：

```ts
import { defineConfig } from 'rolldown';
import postcss from 'rollup-plugin-postcss';
import { dts } from 'rolldown-plugin-dts'

export default defineConfig({
    input: 'src/index.ts',
    output: {
        dir: 'dist',
        format: 'esm'
    },
    plugins: [
        dts(),
        postcss({
            modules: {
                // 自定义类名哈希规则
                generateScopedName: '[name]__[local]___[hash:base64:5]'
            }
        })
    ],
    external: [
        'react',
        'react-dom',
        'axios'
    ]
});
```

关键配置项说明：

| 配置 | 值 | 说明 |
| --- | --- | --- |
| `input` | `src/index.ts` | 库入口，聚合 components / hooks / modules / utils 四类导出 |
| `output.dir` | `dist` | 产物输出目录 |
| `output.format` | `esm` | 仅产出 ESM 格式（与 `"type": "module"` 一致） |
| `plugins.dts` | `dts()` | 生成 TypeScript 类型声明文件 `dist/index.d.ts` |
| `plugins.postcss` | `postcss({ modules })` | 处理 Less 并启用 CSS Modules |
| `generateScopedName` | `[name]__[local]___[hash:base64:5]` | 类名哈希规则，保证样式隔离 |
| `external` | `react`, `react-dom`, `axios` | 不打包进产物，由宿主提供（对齐 `peerDependencies`） |

构建命令由 [packages/ui-components/package.json](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/package.json) 的 `scripts.build` 定义：`rolldown -c ./rolldown.config.ts`，根目录通过 `pnpm run build:ui-components` 触发。

## 产物结构

构建完成后，`dist/` 目录包含两类文件：

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `dist/index.js` | ESM JavaScript | 库的运行时代码，`react` / `react-dom` / `axios` 作为外部依赖由宿主解析 |
| `dist/index.d.ts` | TypeScript 声明 | 类型声明，供消费方 IDE 与类型检查使用 |

由于 [package.json](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/package.json) 中 `"type": "module"` 且 `output.format` 为 `esm`，产物仅 ESM 一种格式，不产出 CJS。

## 发布流程

发布由根 [package.json](file:///Users/linjianguang/code/repo/ui-components/package.json) 的脚本驱动：

```bash
pnpm run publish:ui-components
```

该命令等价于 `pnpm --filter ./packages/ui-components run publish`，执行 [packages/ui-components/scripts/publish.js](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/scripts/publish.js) 完成发布。发布前，根 `package.json` 定义的生命周期钩子 `prepublishOnly` 会先执行构建：

```json
"prepublishOnly": "pnpm run build:ui-components"
```

从而保证发布到 npm 的产物始终是最新源码构建的结果。在实际工程中，该流程由 CI 自动完成，详见 [CI/CD 自动化](./CI-CD-自动化.md)。

## npm 发布配置

[packages/ui-components/package.json](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/package.json) 中与发布相关的字段如下：

```json
"main": "./dist/index.js",
"files": ["dist"],
"publishConfig": {
    "access": "public"
}
```

| 字段 | 值 | 说明 |
| --- | --- | --- |
| `main` | `./dist/index.js` | 兼容旧解析器的入口（指向 ESM 产物） |
| `files` | `["dist"]` | 仅 `dist` 目录被包含进发布的 npm 包，源码与配置不发布 |
| `publishConfig.access` | `public` | 公开发布（scoped 包默认为 restricted，此处显式声明 public） |

### exports 字段的 dev/prod 分离

`exports` 字段按条件区分开发与生产解析路径，是本库的一大特色：

```json
"exports": {
    ".": {
        "types": {
            "development": "./src/index.ts",
            "production": "./dist/index.d.ts",
            "default": "./src/index.ts"
        },
        "import": {
            "development": "./src/index.ts",
            "production": "./dist/index.js",
            "default": "./src/index.ts"
        }
    }
}
```

| 条件 | types 入口 | import 入口 | 适用场景 |
| --- | --- | --- | --- |
| `development` | `./src/index.ts` | `./src/index.ts` | 开发期直接读源码，类型与运行时均为 TS 源文件，便于调试与热更新 |
| `production` | `./dist/index.d.ts` | `./dist/index.js` | 生产期读构建产物，类型走声明文件、运行时走 ESM 产物 |
| `default` | `./src/index.ts` | `./src/index.ts` | 未匹配条件时回退到源码 |

这一设计使得文档站与 monorepo 内部消费方在开发期直接引用源码（配合 [rspress.config.ts](file:///Users/linjianguang/code/repo/ui-components/site/rspress.config.ts) 的别名），而外部消费者在生产构建中拿到的是优化后的 `dist` 产物。

### peerDependencies

库将 React 相关依赖声明为 peer，避免重复实例化：

```json
"peerDependencies": {
    "axios": ">=1.9.0",
    "react": ">=18.0.0",
    "react-dom": ">=18.0.0"
}
```

这与 Rolldown 配置中的 `external` 列表（`react`、`react-dom`、`axios`）一一对应：构建时不打包，运行时由宿主提供。
