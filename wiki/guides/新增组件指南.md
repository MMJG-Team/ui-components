# 新增组件指南

## 简介

本页给出向 `@mmjg/ui-components` 新增一个视图组件的完整步骤。库内所有组件遵循统一的工程约定：目录结构、CSS 变量驱动样式、CSS Modules 隔离、具名 + 默认双导出，以及文档站配套页面。可参考两类既有实现：

- **简单组件**：[Shimmer](../components/Shimmer.md)（纯展示、CSS 变量驱动，无 ref）
- **复杂组件**：[Masonry](../components/Masonry.md)（`forwardRef` + 多个内部 hook + 命令式句柄）

## 步骤

### 1. 创建组件目录

在 [packages/ui-components/src/components/](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/src/components) 下新建以组件名命名的目录，至少包含两个文件：

```
packages/ui-components/src/components/<Name>/
├── index.tsx          # 组件实现
└── style.module.less  # 样式（CSS Modules）
```

若组件较复杂，可在目录下进一步划分 `hooks/`、`models/`、`types.ts` 等，参考 [Masonry](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/src/components/Masonry) 的结构。

### 2. 遵循 CSS 变量驱动模式

库内组件普遍采用「props → CSS 自定义属性 → 关键帧/样式」的链路，而非内联样式。在 `.less` 中于组件根选择器声明 `--vars`，在组件内通过 `useEffect` + `ref.style.setProperty` 写入：

```tsx
const containerRef = useRef<HTMLDivElement>(null);

useEffect(() => {
    if (containerRef.current && typeof width === "number") {
        containerRef.current.style.setProperty("--my-width", `${width}px`);
    }
}, [width]);
```

这样动画与样式完全由 CSS 接管，JS 只在 props 变化时写入变量，避免内联样式导致的重渲染。详见 [CSS Modules 与 Less 规范](./CSS-Modules-与-Less-规范.md)。

### 3. 用 classNames 合成类名

使用 [classnames](https://github.com/JedWatson/classnames) 合并 CSS Modules 类名与外部传入的 `className`：

```tsx
import classNames from "classnames";
import styles from "./style.module.less";

<div className={classNames(styles["my-component"], className)} />
```

注意以 kebab-case 命名的类名需用 `styles["my-component"]` 方括号语法访问。

### 4. 同时导出具名与默认

库约定每个组件同时提供具名导出与默认导出，便于消费方按需选择：

```tsx
export const MyComponent = (props: MyComponentProps) => { /* ... */ };
export default MyComponent;
```

### 5. 注册到 barrel 文件

在 [packages/ui-components/src/components/index.ts](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/src/components/index.ts) 末尾追加一行：

```ts
export * from './MyComponent';
```

该 barrel 文件被库根 [src/index.ts](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/src/index.ts) 通过 `export * from "./components"` 聚合，加入后即可从包入口 `import { MyComponent } from "@mmjg/ui-components"` 使用。

### 6. 需要 ref 控制时使用 forwardRef

若组件需要向外部暴露命令式 API（如滚动控制），使用 `forwardRef` + `useImperativeHandle`，并导出一个对应的 ref 类型：

```tsx
import { forwardRef, useImperativeHandle, useRef } from "react";

export type MyComponentRef = {
    focus: () => void;
    scrollToTop: () => void;
};

export const MyComponent = forwardRef(function InternalMyComponent(
    props: MyComponentProps,
    ref: React.Ref<MyComponentRef>,
) {
    const containerRef = useRef<HTMLDivElement>(null);

    useImperativeHandle(ref, () => ({
        focus: () => containerRef.current?.focus(),
        scrollToTop: () => containerRef.current?.scrollTo({ top: 0 }),
    }), []);

    return <div ref={containerRef}>{/* ... */}</div>;
});

export default MyComponent;
```

参考 [Masonry](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/src/components/Masonry/index.tsx) 的 `MasonryRef`（`getScrollElement` / `scrollToTop` / `scrollIntoView`）与 [types.ts](file:///Users/linjianguang/code/repo/ui-components/packages/ui-components/src/components/Masonry/types.ts)。

### 7. 新增文档页面

在 [site/docs/zh/components/](file:///Users/linjianguang/code/repo/ui-components/site/docs/zh/components) 下新建 `<Name>.mdx`，使用 Rspress 的 `pluginPreview` 预览块展示可交互示例：

````mdx
# MyComponent · 说明

## 基础用法

```tsx preview
import { MyComponent } from "@mmjg/ui-components";

export default function Demo() {
    return <MyComponent width={20} />;
}
```
````

文档站通过 [rspress.config.ts](file:///Users/linjianguang/code/repo/ui-components/site/rspress.config.ts) 的别名直接引用库源码，预览块中的组件会随源码热更新。

### 8. 登记到导航（可选）

Rspress 通过每个目录下的 `_meta.json` 控制侧边栏顺序与标签。当前 [site/docs/zh/_meta.json](file:///Users/linjianguang/code/repo/ui-components/site/docs/zh/_meta.json) 将 `components` 声明为 `type: "dir"`，而 `site/docs/zh/components/` 目录下未提供 `_meta.json`，因此组件页按文件名自动发现并排序。若需自定义顺序或中文标签，可新建 `site/docs/zh/components/_meta.json`：

```json
[
    { "type": "file", "name": "Shimmer", "label": "Shimmer 流光" },
    { "type": "file", "name": "MyComponent", "label": "MyComponent 说明" }
]
```

## 骨架示例

以下是一个最小可用的组件骨架，综合了上述约定（CSS 变量、CSS Modules、classNames、双导出）：

```tsx
// packages/ui-components/src/components/MyComponent/index.tsx
import classNames from "classnames";
import styles from "./style.module.less";
import { useEffect, useRef, type ReactNode } from "react";

export type MyComponentProps = {
    className?: string;
    style?: React.CSSProperties;
    children?: ReactNode;
    /** 高亮颜色，默认白色 */
    color?: string;
    /** 动画周期（秒），默认 2 */
    duration?: number;
};

/**
 * MyComponent 组件
 */
export const MyComponent = (props: MyComponentProps) => {
    const { className, style, children, color = "#ffffff", duration = 2 } = props;
    const containerRef = useRef<HTMLDivElement>(null);

    // props → CSS 变量
    useEffect(() => {
        if (containerRef.current) {
            containerRef.current.style.setProperty("--my-color", color);
        }
    }, [color]);

    useEffect(() => {
        if (containerRef.current && typeof duration === "number") {
            containerRef.current.style.setProperty("--my-duration", `${duration}s`);
        }
    }, [duration]);

    return (
        <div
            ref={containerRef}
            className={classNames(styles["my-component"], className)}
            style={style}
        >
            {children}
        </div>
    );
};

export default MyComponent;
```

```less
/* packages/ui-components/src/components/MyComponent/style.module.less */
.my-component {
    --my-color: #ffffff;
    --my-duration: 2s;

    color: var(--my-color);
    animation: my-fade var(--my-duration) linear infinite;

    @keyframes my-fade {
        0% { opacity: 0.4; }
        50% { opacity: 1; }
        100% { opacity: 0.4; }
    }
}
```
