## 依赖分层

库本体 [packages/ui-components/package.json](../packages/ui-components/package.json) 的依赖分三类：

### dependencies（运行时打包进产物）
- `classnames` `2.5.1`
- `lodash-es` `4.17.21`
- `mitt` `^3.0.1`

### peerDependencies（宿主必须提供）
- `axios` `>=1.9.0`
- `react` `>=18.0.0`
- `react-dom` `>=18.0.0`

### devDependencies（仅开发期）
- `@types/lodash-es`、`@types/node`、`@types/react`、`@types/react-dom`
- `rolldown`、`rolldown-plugin-dts`、`rollup-plugin-postcss`
- `less`、`typescript`

> `react`/`react-dom`/`axios` 同时出现在 devDeps（固定版本开发）与 peerDeps（声明宿主范围），并在 [rolldown.config.ts](../packages/ui-components/rolldown.config.ts) 的 `external` 中排除，不打入产物。

## 各依赖的用途落点

| 依赖 | 用在哪 | 说明 |
| --- | --- | --- |
| `classnames` | 所有组件 | 拼接 CSS Modules 类名与外部 className |
| `lodash-es` | `debounce` 用于 [Masonry](../packages/ui-components/src/components/Masonry/index.tsx) 的 onResize、[useAutoLoadMore](../packages/ui-components/src/hooks/useAutoLoadMore.ts)；`throttle` 用于 [VerticalViewportMonitor](../packages/ui-components/src/modules/VerticalViewportMonitor.ts) | ESM tree-shaking 友好 |
| `mitt` | [SyncTaskQueue](../packages/ui-components/src/modules/SyncTaskQueue.ts) | 任务完成事件广播 |
| `axios` | [UniqueRequest](../packages/ui-components/src/modules/UniqueRequest.ts) | 仅借用 `AxiosError.ERR_CANCELED` 与 `AxiosRequestConfig` 类型 + 取消语义 |
| `react`/`react-dom` | hooks、组件 | peer，不打入产物 |

## Node 引擎约束

```json
"engines": {
    "node": "^20.19.0 || >=22.12.0"
}
```

CI（见 [release-npm-pkg.yml](../.github/workflows/release-npm-pkg.yml)）固定使用 Node `22.18.0` + pnpm `10.12.1`。

## exports 字段：开发态直连源码

[package.json](../packages/ui-components/package.json) 的 `exports` 对不同条件返回不同入口：

```json
".": {
    "types":   { "development": "./src/index.ts",     "production": "./dist/index.d.ts" },
    "import":  { "development": "./src/index.ts",     "production": "./dist/index.js"  }
}
```

- **development**（默认）：直接指向 `src/index.ts`，文档站/调试期免构建。
- **production**：指向 `dist/index.js` + `dist/index.d.ts`，发布产物。

文档站 [rspress.config.ts](../site/rspress.config.ts) 又额外用别名 `@mmjg/ui-components → ../packages/ui-components/src/index.ts` 强制锁定到源码，确保文档示例永远调试最新代码。

## 文档站依赖（site 侧）

[site/package.json](../site/package.json) 关键依赖：

- `@mmjg/ui-components: workspace:*` —— 通过工作区引用库。
- `@rspress/core ^2.0.13` + `@rspress/plugin-preview ^2.0.14` —— 文档框架与 mdx 实时预览。
- `@rsbuild/plugin-less ^1.6.4` —— Less 支持。
- `@rsbuild/plugin-node-polyfill ^1.4.6` —— Node polyfill（部分库需要）。
