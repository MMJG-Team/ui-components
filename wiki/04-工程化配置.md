# 04 · 工程化配置

本章梳理项目中所有与构建、类型、包管理、文档站点相关的工程化配置文件。

## TypeScript 配置

项目有两份 `tsconfig.json`，配置基本一致但 `include` 与产物策略不同。

### 库本体 [packages/ui-components/tsconfig.json](../packages/ui-components/tsconfig.json)

关键项：

```jsonc
{
    "compilerOptions": {
        "lib": ["DOM", "ES2020", "dom.iterable"],
        "jsx": "react-jsx",          // 新版 JSX 转换，无需 import React
        "target": "ES2020",
        "module": "ESNext",
        "moduleResolution": "bundler",
        "verbatimModuleSyntax": true, // 强制 type-only import 用 import type
        "allowImportingTsExtensions": true,
        "isolatedModules": true,
        "noUncheckedSideEffectImports": true,
        "strict": true,
        "noUnusedLocals": true,
        "noUnusedParameters": true,
        "noEmit": true,               // 由 rolldown 负责产物
        // 仅库本体多了 declaration 相关：
        "outDir": "./types",
        "declaration": true,
        "emitDeclarationOnly": true
    },
    "include": ["src", "rolldown.config.ts", "global.d.ts"]
}
```

### 根 [tsconfig.json](../tsconfig.json)

`include` 为 `["docs", "global.d.ts"]`，无 `declaration` 相关项，服务于文档站类型检查。

### 需特别注意的严格项

| 选项 | 含义 | 对编码的影响 |
| --- | --- | --- |
| `strict` | 开启全部严格检查 | 禁止隐式 any、null 检查等 |
| `noUnusedLocals` / `noUnusedParameters` | 未使用的变量/参数报错 | 解构 props 时不能留无用字段 |
| `verbatimModuleSyntax` | 区分值导入与类型导入 | 类型必须 `import type` / `export type *` |
| `isolatedModules` | 每文件独立编译 | 禁止 `export const enum` 跨文件常量折叠（库内用普通 `enum`） |
| `allowImportingTsExtensions` | 允许 import 带 `.ts` 后缀 | 文档站可直接 import `.tsx` demo |

> 因 `verbatimModuleSyntax`，库内类型重导出普遍写作 `export type * from "./types"`（见 [Masonry/index.tsx](../packages/ui-components/src/components/Masonry/index.tsx)）。

## 全局类型声明 [global.d.ts](../packages/ui-components/global.d.ts)

为非 JS 资源补充模块声明：

```ts
declare module "*.json"   { const value: any; export default value; }
declare module "*.svg"    { const content: string; export default content; }
declare module "*.png"    { const content: string; export default content; }
declare module "*.gif"    { const content: string; export default content; }
declare module '*.module.less' {
    const classes: { readonly [key: string]: string };
    export default classes;
}
```

根目录与 `packages/ui-components/` 下各有一份相同文件。

## 打包配置 [rolldown.config.ts](../packages/ui-components/rolldown.config.ts)

```ts
export default defineConfig({
    input: 'src/index.ts',
    output: { dir: 'dist', format: 'esm' },
    plugins: [
        dts(),                                   // 生成 .d.ts
        postcss({
            modules: {
                generateScopedName: '[name]__[local]___[hash:base64:5]'
            }
        })
    ],
    external: ['react', 'react-dom', 'axios']    // peer 不打入
});
```

要点：
- **单一 ESM 产物**到 `dist/`，无 CJS。
- CSS Modules 类名哈希规则 `[name]__[local]___[hash:base64:5]`，例如 `style__border-effect___a1b2c`。
- `react`/`react-dom`/`axios` 标记为 external。
- `dts()` 插件生成类型声明文件。

## pnpm Workspace

[pnpm-workspace.yaml](../pnpm-workspace.yaml)：

```yaml
packages:
    - "site"
    - "packages/*"
```

site 通过 `"@mmjg/ui-components": "workspace:*"` 引用库（见 [site/package.json](../site/package.json)）。

## 文档站配置 [rspress.config.ts](../site/rspress.config.ts)

```ts
export default defineConfig({
    lang: 'zh',
    base: 'ui-components',          // GitHub Pages 子路径
    root: './docs',
    title: '@mmjg/ui-components',
    icon: '/cat-logo-02.png',
    plugins: [pluginPreview({ defaultRenderMode: 'pure' })],
    locales: [{ lang: 'zh', label: '简体中文', ... }],
    builderConfig: {
        resolve: {
            alias: {
                '@assets': './docs/assets',
                '@demo': './docs/_demo',
                '@mmjg/ui-components': '../packages/ui-components/src/index.ts'  // 关键别名
            }
        },
        plugins: [pluginLess()],
    }
});
```

- `pluginPreview`：支持 mdx 中 ` ```tsx preview ` 实时预览组件。
- `pluginLess`：让文档站也能直接写 Less。
- 别名 `@mmjg/ui-components` 锁定到库源码，文档与库同源调试。

## 文档目录约定

文档根 `site/docs/zh/`，导航由 [_meta.json](../site/docs/zh/_meta.json) 驱动：

```json
[
    { "type": "file", "name": "index", "label": "首页" },
    { "type": "file", "name": "/intro", "label": "简介" },
    { "type": "dir",  "name": "components", "label": "组件" },
    { "type": "dir",  "name": "hooks", "label": "hooks" },
    { "type": "dir",  "name": "modules", "label": "模块" },
    { "type": "dir",  "name": "utils", "label": "工具" }
]
```

每个分类目录下又有各自的 `_meta.json` 控制子项排序。组件 demo 放在 `site/docs/_demo/components/<Name>/`。

## .gitignore 要点

[.gitignore](../.gitignore) 忽略 `node_modules`、`dist`、`doc_build`（文档构建产物）、`.env*`、`.DS_Store` 等。
