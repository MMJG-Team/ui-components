# 简介 📦

@mmjg/ui-components 是一个 [MMJG-Team](https://github.com/MMJG-Team) 在研发过程中沉淀出来的组件库，技术栈基于 **React**，其中包含 视图组件，React Hooks，以及一些通用的功能模块

## 安装方式 📥

import { PackageManagerTabs } from "@rspress/core/theme";

<PackageManagerTabs command="add @mmjg/ui-components" />

## 贡献指南 🔧

**使用 git 拉取仓库**

```bash
git clone git@github.com:MMJG-Team/ui-components.git
```

**启动文档服务** 🚀

进入到仓库根目录下，执行启动脚本

```bash
pnpm run dev
```

**构建文档** 📚

```bash
pnpm run build:docs
```
