# Cube 立方体

Cube 是一个3D旋转立方体组件，用于展示炫酷的3D视觉效果。 ✨

:::tip 特性

- **自动旋转** 🔍：立方体自动旋转动画，持续展示3D效果
- **自定义尺寸** 📏：支持自定义立方体大小，适配不同展示场景
- **自定义渲染** ⚡：支持自定义渲染每个面，实现丰富的内容展示
- **6个面** 📐：立方体包含前、后、左、右、上、下6个面
- **3D效果** 🎨：使用CSS 3D变换，实现真实的立方体视觉效果

:::

### 自定义渲染面 ⚡

通过 `customRenderFace` 属性自定义每个面的内容，实现丰富的展示效果。

```tsx preview
import React from "react";
import { Cube } from "@mmjg/ui-components";

const GradientDemo: React.FC = () => {
    const customRenderFace = (face: string) => {
        const gradients: Record<string, string> = {
            front: "linear-gradient(135deg, #667eea 0%, #764ba2 100%)",
            back: "linear-gradient(135deg, #f093fb 0%, #f5576c 100%)",
            left: "linear-gradient(135deg, #4facfe 0%, #00f2fe 100%)",
            right: "linear-gradient(135deg, #43e97b 0%, #38f9d7 100%)",
            top: "linear-gradient(135deg, #fa709a 0%, #fee140 100%)",
            bottom: "linear-gradient(135deg, #a8edea 0%, #fed6e3 100%)",
        };

        return (
            <div
                style={{
                    width: "100%",
                    height: "100%",
                    background:
                        gradients[face] ||
                        "linear-gradient(135deg, #667eea 0%, #764ba2 100%)",
                    display: "flex",
                    alignItems: "center",
                    justifyContent: "center",
                    color: "white",
                    fontSize: "18px",
                    fontWeight: "bold",
                    textShadow: "2px 2px 4px rgba(0, 0, 0, 0.3)",
                }}
            >
                {face.toUpperCase()}
            </div>
        );
    };

    return (
        <div
            style={{
                display: "flex",
                justifyContent: "center",
                padding: "20px",
                background: "var(--rp-c-bg-soft)",
                borderRadius: "4px",
            }}
        >
            <Cube size={140} customRenderFace={customRenderFace} />
        </div>
    );
};

export default GradientDemo;
```

通过 `rotateClassName` 属性自定义旋转动画，实现不同的旋转效果。

                padding: "20px",
                background: "var(--rp-c-bg)",

## API 📚

### CubeProps ⚙️

| 属性             | 说明               | 类型                            | 默认值       | 版本 |
| ---------------- | ------------------ | ------------------------------- | ------------ | ---- |
| size             | 立方体尺寸（像素） | `number`                        | 100          | -    |
| padding          | 容器内边距（像素） | `number`                        | 50           | -    |
| autoRotate       | 是否自动旋转       | `boolean`                       | true         | -    |
| customRenderFace | 自定义渲染面的函数 | `(face: CubeFace) => ReactNode` | 随机颜色方块 | -    |
| rootClassName    | 根容器自定义类名   | `string`                        | -            | -    |
| rotateClassName  | 旋转核心自定义类名 | `string`                        | -            | -    |

### CubeFace 类型定义

```typescript
enum CubeFace {
    Front = "front", // 前面
    Back = "back", // 后面
    Left = "left", // 左面
    Right = "right", // 右面
    Top = "top", // 上面
    Bottom = "bottom", // 下面
}
```

:::tip

- 立方体包含6个面，每个面都可以单独渲染
- `customRenderFace` 函数接收 `CubeFace` 参数，返回对应面的内容
- 默认渲染为随机颜色的方块

:::
