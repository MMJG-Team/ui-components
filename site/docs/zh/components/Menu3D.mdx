# Menu3D 3D旋转菜单

Menu3D 是一个炫酷的 3D 旋转菜单组件，支持自动旋转、鼠标拖拽控制和交互式菜单选择。 🎯

- **3D视觉效果** 🔍：使用 CSS 3D transform 实现立体旋转效果
- **自动旋转** 📱：默认自动旋转，鼠标悬停时暂停
- **拖拽控制** ⚡：支持鼠标拖拽调整旋转角度
- **交互式菜单** 📐：点击菜单项触发回调事件
- **流畅动画** 🎨：使用 requestAnimationFrame 实现流畅的旋转动画

## API 📚

### Menu3DProps ⚙️

| 属性               | 说明                 | 类型                              | 默认值 | 版本 |
| ------------------ | -------------------- | --------------------------------- | ------ | ---- |
| menus              | 菜单数据数组         | `Menu[]`                          | -      | -    |
| menuClassName      | 菜单项的自定义类名   | `string`                          | -      | -    |
| rotateRadius       | 旋转半径（像素）     | `number`                          | 200    | -    |
| backfaceVisibility | 是否显示菜单项背面   | `boolean`                         | true   | -    |
| customItemRender   | 自定义菜单项渲染函数 | `(menu: Menu) => React.ReactNode` | -      | -    |
| onMenuClick        | 菜单点击回调函数     | `(menuId: string) => void`        | -      | -    |

### Menu 类型定义 🔖

```typescript
type Menu = {
    id: string;
    title: string;
    icon: React.ReactNode;
};
```

## 特性说明 🎯

### 3D旋转效果

组件使用 CSS 3D transform 实现立体旋转效果：

- `perspective: 1200px` - 设置透视距离
- `transform-style: preserve-3d` - 保持3D空间
- `backface-visibility: hidden` - 隐藏背面

### 自动旋转动画

- 默认自动旋转，速度为 0.2度/帧
- 鼠标悬停时暂停旋转
- 鼠标离开后恢复旋转
- 使用 requestAnimationFrame 实现流畅动画

### 拖拽控制

- 支持鼠标拖拽调整旋转角度
- 拖拽偏移量转换为旋转角度（偏移量 \* 0.2）
- 拖拽结束后恢复自动旋转

### 菜单项布局

- 菜单项均匀分布在360度圆周上
- 每个菜单项的角度间隔为 `360 / menus.length`
- 菜单项使用 `translateZ(rotateRadius)` 向外延伸，形成立体效果

### 动态透明度效果

- 菜单项根据旋转角度自动调整透明度
- 透明度计算公式：`opacity = |180 - (当前角度 % 360)| / 180`
- 面向用户的菜单项（角度接近0或360）透明度接近1，清晰可见
- 背向用户的菜单项（角度接近180）透明度接近0，逐渐模糊
- 提供更自然的3D视觉效果和深度感

### 自定义旋转半径

- 通过 `rotateRadius` 属性调整菜单项距离中心的距离
- 默认值为 200px，可以根据需要调整
- 较小的半径使菜单项更靠近中心，适合紧凑布局
- 较大的半径使菜单项更分散，适合展示更多内容

### 背面显示控制

- 通过 `backfaceVisibility` 属性控制是否显示菜单项背面
- 默认值为 true，显示背面（使用 `backface-visibility: visible`）
- 设置为 false 时隐藏背面（使用 `backface-visibility: hidden`）
- 隐藏背面可以避免菜单项翻转时的视觉干扰

## 最佳实践 💡

1. **菜单设计**：
    - 使用简洁明了的图标和标题
    - 保持菜单项数量适中（5-10个）
    - 为每个菜单项提供清晰的 id 标识

2. **交互反馈**：
    - 在 `onMenuClick` 回调中提供明确的反馈
    - 可以结合路由跳转或页面滚动

3. **样式定制**：
    - 可以通过修改 Less 样式文件定制外观
    - 调整颜色、阴影、圆角等视觉效果

4. **响应式考虑**：
    - 在移动设备上可能需要调整菜单大小
    - 考虑在小屏幕上使用替代方案

5. **旋转半径选择**：
    - 根据菜单项数量选择合适的半径
    - 测试不同半径值，找到最佳视觉效果

6. **自定义渲染**：
    - 使用 `customItemRender` 实现完全自定义的菜单项样式
    - 可以添加动画效果、交互元素等
    - 保持自定义样式与整体设计风格一致

7. **透明度优化**：
    - 利用动态透明度效果增强用户体验
    - 面向用户的菜单项更突出，便于点击
    - 背向的菜单项淡化，减少视觉干扰
