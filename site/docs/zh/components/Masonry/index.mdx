# Masonry 瀑布流

Masonry 是一个高性能的瀑布流布局组件，支持自适应列数、响应式布局、虚拟滚动优化和灵活的内容渲染。 🎯

- **自适应列宽** 🔍：根据容器宽度自动调整列宽
- **响应式布局** 📱：支持自定义断点配置
- **性能优化** ⚡：实现虚拟滚动，仅渲染可见区域内的内容
- **高度自适配** 📐：根据内容原始宽高比自动计算显示高度
- **灵活的渲染** 🎨：支持自定义内容渲染函数

## API 📚

### MasonryProps ⚙️

| 属性              | 说明                                                     | 类型                                                                                                            | 默认值 | 版本 |
| ----------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------ | ---- |
| items             | 数据源，必须包含id、src、naturalWidth、naturalHeight字段 | `Array<{ id: string \| number; src: string; naturalWidth: number; naturalHeight: number; [key: string]: any }>` | -      | -    |
| gap               | 网格间距（像素）                                         | `number`                                                                                                        | 8      | -    |
| columnCount       | 固定列数，如果提供则优先级高于breakPointConfig           | `number`                                                                                                        | -      | -    |
| breakPointConfig  | 响应式断点配置，键为容器宽度阈值，值为对应的列数         | `Record<number, number>`                                                                                        | -      | -    |
| itemRender        | 自定义渲染函数                                           | `React.FC<{ data: Item }>`                                                                                      | -      | -    |
| footerClassName   | 页脚类名                                                 | `string`                                                                                                        | -      | -    |
| footer            | 页脚内容                                                 | `React.ReactNode`                                                                                               | -      | -    |
| loadMoreThreshold | 加载更多触发阈值，默认值为 100                           | `number`                                                                                                        | 100    | -    |
| onLoadMore        | 加载更多回调，当滚动到可见区域底部时触发                 | `() => void`                                                                                                    | -      | -    |

## 类型定义 🔖

```typescript
import type { FC } from "react";

/**
 * 瀑布流组件属性
 */
export type MasonryProps<
    Item extends {
        id: string | number;
        src: string;
        naturalWidth: number;
        naturalHeight: number;
    },
> = {
    // 数据
    items: Item[];
    // 断点配置
    breakPointConfig?: Record<number, number>;
    // 列数
    columnCount?: number;
    // 间距
    gap?: number;
    // 项渲染函数
    itemRender?: FC<{
        data: Item;
    }>;
};
```

## 注意事项 ⚠️

1. **性能优化** ⚡：
    - 组件内部实现了虚拟滚动，仅渲染可见区域内的内容
    - 通过overscanHeight参数预加载屏幕外内容，提高滚动体验

2. **数据要求** 📋：
    - 传入的items数据必须包含id、src、naturalWidth和naturalHeight字段
    - 确保naturalWidth和naturalHeight反映了内容的真实宽高比

3. **响应式布局** 📱：
    - 当同时设置columnCount和breakPointConfig时，columnCount优先级更高
    - 断点配置应按从小到大的顺序设置，组件会自动选择合适的列数

4. **容器要求** 📦：
    - 组件应放在可滚动的容器内，或容器应设置适当的高度
    - 容器宽度变化时，组件会自动重新计算布局
