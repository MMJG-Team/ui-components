# useMockProgress 模拟进度

## 概述

`useMockProgress` 是一个 React 自定义钩子，用于模拟进度条动画效果，特别适用于需要展示异步操作进度但无法获取真实进度数据的场景。该钩子提供了高度自定义的进度控制功能

:::tip 导入

```tsx
import { useMockProgress } from "@mmjg/ui-components";
```

:::

## 使用示例

### 基本使用

```tsx preview
import React from "react";
import { useMockProgress } from "@mmjg/ui-components";

const ProgressDemo: React.FC = () => {
    const { progress, start, complete, stop } = useMockProgress();

    const handleStart = () => {
        start();
    };

    const handleComplete = () => {
        complete();
    };

    const handleStop = () => {
        stop();
    };

    return (
        <div>
            <div
                style={{
                    width: "100%",
                    height: "10px",
                    backgroundColor: "#f0f0f0",
                    borderRadius: "10px",
                    overflow: "hidden",
                }}
            >
                <div
                    style={{
                        width: `${progress}%`,
                        height: "100%",
                        backgroundColor: "var(--rp-c-brand)",
                        transition: "width 0.3s ease",
                    }}
                />
            </div>
            <p style={{ margin: "10px 0" }}>当前进度: {progress}%</p>

            <div style={{ display: "flex", gap: "10px" }}>
                <button
                    onClick={handleStart}
                    style={{
                        padding: "4px 16px",
                        borderRadius: "4px",
                        background: "var(--rp-c-brand)",
                        color: "#fff",
                        cursor: "pointer",
                    }}
                >
                    开始
                </button>
                <button
                    onClick={handleComplete}
                    style={{
                        padding: "4px 16px",
                        borderRadius: "4px",
                        background: "var(--rp-c-bg-soft)",
                        color: "var(--rp-c-text-1)",
                        cursor: "pointer",
                    }}
                >
                    完成
                </button>
                <button
                    onClick={handleStop}
                    style={{
                        padding: "4px 16px",
                        borderRadius: "4px",
                        background: "var(--rp-c-bg-soft)",
                        color: "var(--rp-c-text-1)",
                        cursor: "pointer",
                    }}
                >
                    停止
                </button>
            </div>
        </div>
    );
};

export default ProgressDemo;
```

### 与异步操作结合

```tsx preview
import React from "react";
import { useMockProgress } from "@mmjg/ui-components";

const AsyncOperationDemo: React.FC = () => {
    const { progress, start, complete } = useMockProgress();
    const [status, setStatus] = React.useState<"idle" | "loading" | "success">(
        "idle",
    );

    const performAsyncOperation = async () => {
        setStatus("loading");
        start(); // 开始模拟进度

        try {
            // 模拟耗时操作
            await new Promise((resolve) => setTimeout(resolve, 3000));
            setStatus("success");
        } catch (error) {
            console.error("操作失败:", error);
        } finally {
            complete(); // 完成进度
        }
    };

    return (
        <div>
            <div
                style={{
                    width: "100%",
                    height: "10px",
                    backgroundColor: "#f0f0f0",
                    borderRadius: "10px",
                    overflow: "hidden",
                }}
            >
                <div
                    style={{
                        width: `${progress}%`,
                        height: "100%",
                        backgroundColor:
                            status === "success" ? "#4CAF50" : "#2196F3",
                        transition: "width 0.3s ease",
                    }}
                />
            </div>

            <button
                style={{
                    marginTop: "12px",
                    padding: "4px 12px",
                    borderRadius: "5px",
                    background: "var(--rp-c-brand)",
                    color: "#fff",
                    cursor: "pointer",
                }}
                onClick={performAsyncOperation}
                disabled={status === "loading"}
            >
                {status === "idle"
                    ? "开始"
                    : status === "loading"
                      ? "处理中..."
                      : "重新开始"}
            </button>
        </div>
    );
};

export default AsyncOperationDemo;
```

### 自定义进度参数

通过配置参数自定义进度条的行为，包括步长、停止条件和更新间隔。

```tsx preview
import React, { useState } from "react";
import { useMockProgress } from "@mmjg/ui-components";

const CustomConfigDemo: React.FC = () => {
    const [step, setStep] = useState(5);
    const [stopCondition, setStopCondition] = useState(95);
    const [updateInterval, setUpdateInterval] = useState(200);

    const { progress, start, complete, stop } = useMockProgress({
        step,
        stopCondition,
        updateInterval,
    });

    const handleStart = () => {
        start();
    };

    return (
        <div>
            <div
                style={{
                    width: "100%",
                    height: "8px",
                    background: "#f0f0f0",
                    borderRadius: "4px",
                    overflow: "hidden",
                }}
            >
                <div
                    style={{
                        width: `${progress}%`,
                        height: "100%",
                        background: "var(--rp-c-brand)",
                        transition: "width 0.2s ease",
                    }}
                />
            </div>

            <div style={{ margin: "10px 0", color: "var(--rp-c-text-1)" }}>
                当前进度: {progress}%
            </div>

            <div
                style={{
                    display: "flex",
                    flexDirection: "column",
                    gap: "10px",
                    padding: "10px",
                    borderRadius: "10px",
                    marginBottom: "10px",
                    color: "var(--rp-c-text-2)",
                    background: "var(--rp-c-bg-soft)",
                }}
            >
                配置参数:
                <div
                    style={{
                        display: "flex",
                        alignItems: "center",
                        gap: "4px",
                    }}
                >
                    <label>步长: </label>
                    <input
                        type="number"
                        value={step}
                        onChange={(e) => setStep(Number(e.target.value))}
                        style={{
                            padding: "2px 8px",
                            borderRadius: "4px",
                            border: "1px solid var(--rp-c-border)",
                            background: "var(--rp-c-bg)",
                            color: "var(--rp-c-text-1)",
                        }}
                    />
                    %
                </div>
                <div
                    style={{
                        display: "flex",
                        alignItems: "center",
                        gap: "4px",
                    }}
                >
                    <label>停止条件: </label>
                    <input
                        type="number"
                        value={stopCondition}
                        onChange={(e) =>
                            setStopCondition(Number(e.target.value))
                        }
                        style={{
                            padding: "4px 8px",
                            borderRadius: "4px",
                            border: "1px solid var(--rp-c-border)",
                            background: "var(--rp-c-bg)",
                            color: "var(--rp-c-text-1)",
                        }}
                    />
                    %
                </div>
                <div
                    style={{
                        display: "flex",
                        alignItems: "center",
                        gap: "4px",
                    }}
                >
                    <label>更新间隔: </label>
                    <input
                        type="number"
                        value={updateInterval}
                        onChange={(e) =>
                            setUpdateInterval(Number(e.target.value))
                        }
                        style={{
                            padding: "4px 8px",
                            borderRadius: "4px",
                            border: "1px solid var(--rp-c-border)",
                            background: "var(--rp-c-bg)",
                            color: "var(--rp-c-text-1)",
                        }}
                    />
                    ms
                </div>
            </div>

            <div style={{ display: "flex", gap: "10px", marginTop: "10px" }}>
                <button
                    onClick={handleStart}
                    style={{
                        padding: "4px 16px",
                        borderRadius: "4px",
                        background: "var(--rp-c-brand)",
                        color: "#fff",
                        cursor: "pointer",
                    }}
                >
                    开始
                </button>
                <button
                    onClick={complete}
                    style={{
                        padding: "4px 16px",
                        borderRadius: "4px",
                        background: "var(--rp-c-bg-soft)",
                        color: "var(--rp-c-text-1)",
                        cursor: "pointer",
                    }}
                >
                    完成
                </button>
                <button
                    onClick={stop}

                        padding: "4px 16px",
                        borderRadius: "4px",
                        background: "var(--rp-c-bg-soft)",
                        color: "var(--rp-c-text-1)",
                        cursor: "pointer",
                    }}
                >

            </div>
        </div>
    );
};
```

## API

### useMockProgress(options)

#### 参数

| 参数      | 类型     | 描述                           |
| --------- | -------- | ------------------------------ |
| `options` | `object` | 配置选项，用于自定义进度条行为 |

#### options 配置项

| 属性             | 类型                     | 默认值 | 描述                         |
| ---------------- | ------------------------ | ------ | ---------------------------- |
| `step`           | `number \| () => number` | 10     | 每次进度增加的步长（百分比） |
| `stopCondition`  | `number \| () => number` | 90     | 进度停止的阈值（百分比）     |
| `updateInterval` | `number \| () => number` | 100    | 更新进度的间隔时间（毫秒）   |

:::tip

所有配置参数都支持函数形式，可以在每次更新时动态计算参数值。

:::

#### 返回值

返回一个对象，包含以下属性和方法：

| 属性/方法    | 类型       | 描述                                        |
| ------------ | ---------- | ------------------------------------------- |
| `progress`   | `number`   | 当前进度值，范围从 0 到 100                 |
| `start()`    | `function` | 启动进度动画，从 0 开始，按配置参数逐步增加 |
| `complete()` | `function` | 完成进度，直接将进度设置为 100 并停止动画   |
| `stop()`     | `function` | 停止进度动画，保持当前进度值                |

### IUseMockProgressOptions 类型定义

```typescript
type IUseMockProgressOptions = {
    step?: number | (() => number);
    stopCondition?: number | (() => number);
    updateInterval?: number | (() => number);
};
```

## 注意事项

1. **内存泄漏防护**：钩子内部使用了 `useRef` 来保存定时器引用，并在 `stop` 方法中清除定时器，以防止内存泄漏。

2. **进度限制**：模拟进度默认最多增长到 90%，预留 10% 的空间用于 `complete` 方法调用时的最终完成效果，这是一种常见的用户体验优化。

3. **使用场景**：此钩子特别适用于：
    - 文件上传/下载模拟
    - 数据加载状态展示
    - 表单提交反馈
    - 任何需要向用户展示操作进度但无法获取真实进度百分比的场景

4. **自定义**：可以根据需要调整进度增长的速度和步长，默认每 100ms 增加 10%。

5. **动态配置参数**：
    - 所有配置参数（`step`、`stopCondition`、`updateInterval`）都支持函数形式
    - 函数会在每次进度更新时被调用，可以根据当前状态动态调整参数
    - 动态配置适用于需要根据用户交互或其他条件调整进度行为的场景
    - 使用动态配置时，确保函数的返回值在合理范围内，避免性能问题

6. **配置参数建议值**：
    - `step`：建议值 3-20，过小会导致进度更新缓慢，过大会导致进度跳跃明显
    - `stopCondition`：建议值 85-98，预留空间用于完成效果
    - `updateInterval`：建议值 20-300ms，过快会占用更多资源，过慢会降低用户体验

7. **参数类型选择**：
    - 固定值：适用于进度行为固定的场景，代码更简洁
    - 函数形式：适用于需要动态调整的场景，更灵活但代码稍复杂
    - 根据实际需求选择合适的参数类型
