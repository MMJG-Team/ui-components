# 简介 📦

@mmjg/ui-components 是面向 UI 开发场景打造的公共组件与工具通用库，核心服务于前端 UI 开发工作，聚焦整合各类可复用的前端能力，为整体 UI 体系提供标准化、通用化的技术支撑。

## 安装方式 📥

import { PackageManagerTabs } from "@rspress/core/theme";

<PackageManagerTabs command="add @mmjg/ui-components" />

## 贡献指南 🔧

**使用 git 拉取仓库**

```bash
git clone git@github.com:MMJG-Team/ui-components.git
```

**启动文档服务** 🚀

进入到仓库根目录下，执行启动脚本

```bash
pnpm run dev
```

**构建文档** 📚

```bash
pnpm run build:docs
```
