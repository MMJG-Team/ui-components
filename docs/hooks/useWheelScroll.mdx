# useWheelScroll

## 概述

`useWheelScroll` 是一个 React 自定义钩子，用于实现水平滚动容器的鼠标滚轮和拖拽功能。该钩子特别适用于标签栏等水平布局组件，提供了平滑的水平滚动体验，支持通过鼠标滚轮和拖拽两种方式进行内容导航。

## 导入

```tsx
import { useWheelScroll } from 'aippt-plugin-common';
```

## 使用示例

### 基本使用

```tsx preview
import React from 'react';
import { useWheelScroll } from 'aippt-plugin-common';

const HorizontalScrollContainer: React.FC = () => {
  const { elementRef, onWheel, onMouseDown } = useWheelScroll();

  // 示例标签数据
  const tabs = Array.from({ length: 20 }, (_, i) => `Tab ${i + 1}`);

  return (
    <div 
      ref={elementRef}
      onWheel={onWheel}
      onMouseDown={onMouseDown}
      style={{
        display: 'flex',
        overflowX: 'auto',
        whiteSpace: 'nowrap',
        padding: '10px',
        border: '1px solid #ccc',
        borderRadius: '4px',
        cursor: 'grab',
        // 隐藏滚动条但保留功能
        scrollbarWidth: 'none', /* Firefox */
        '&::-webkit-scrollbar': { display: 'none' } /* Chrome, Safari, Edge */
      }}
    >
      {tabs.map((tab, index) => (
        <div
          key={index}
          style={{
            display: 'inline-block',
            padding: '8px 16px',
            marginRight: '8px',
            backgroundColor: '#999999ff',
            borderRadius: '4px',
            userSelect: 'none'
          }}
        >
          {tab}
        </div>
      ))}
    </div>
  );
};

export default HorizontalScrollContainer;
```

## API

### useWheelScroll(options?)

- 参数

| 参数名 | 类型 | 默认值 | 必填 | 描述 |
|-------|------|-------|-----|------|
| `options` | `Object` | `undefined` | 否 | 配置选项 |
| `options.excludeClassName` | `string` | `undefined` | 否 | 要排除的元素类名。如果鼠标事件目标是带有此类名的元素或其子元素，滚动事件将被忽略 |

-  返回值

| 属性名 | 类型 | 描述 |
|-------|------|------|
| `elementRef` | `React.RefObject<HTMLDivElement>` | 要应用滚动功能的容器元素引用 |
| `onWheel` | `(e: React.WheelEvent<HTMLDivElement>) => void` | 鼠标滚轮事件处理函数 |
| `onMouseDown` | `(e: React.MouseEvent<HTMLDivElement>) => void` | 鼠标按下事件处理函数，用于启动拖拽功能 |
