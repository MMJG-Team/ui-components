# @mmjg/ui-components

@mmjg/ui-components 是一个 [MMJG-Team](https://github.com/MMJG-Team) 在研发过程中沉淀出来的组件库，技术栈基于 **React**，其中包含 视图组件，React Hooks，以及一些通用的功能模块

## 安装方式 📥

**使用 pnpm**

```bash
pnpm add @mmjg/ui-components
```

## 维护方式 🔧

**启动文档服务** 🚀

```bash
# 启动开发服务器
pnpm run dev
```

**构建文档** 📚

```bash
pnpm run build:docs
```
